# Tetris

This is a modernized implementation of the classic game Tetris. It was made with Rust and Macroquad.

It was made mostly using AI agents, and is not a measure of my skills.

## Running
### Building
Debug:
```sh
cargo build
```
Release:
```sh
cargo build --release
```
### Running
Debug:
```sh
cargo run
```
Release:
```sh
cargo run --release
```
